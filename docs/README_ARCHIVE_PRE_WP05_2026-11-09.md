## Start from the complete project ZIP

1. Install **Node.js 24 with npm**.
2. Extract `FCC_Stained_Glass_WP02_Source.zip` to a folder of your choice. Paths with spaces are supported.
3. Open PowerShell in the extracted `fcc-stained-glass` directory containing `package.json`.
4. Run these commands one at a time:

```powershell
node --version
npm.cmd --version
npm.cmd ci
npm.cmd run dev
```

`node --version` should begin with `v24.`. Open the local address printed by the server, normally `http://127.0.0.1:5173/`. Choose **Coloring pages**, then **View drawing** for **Sun, moon, star and waves**. **Original photo** opens the reviewed photograph. Stop the server with **Ctrl+C**.

The Windows examples use `npm.cmd`, so they work when PowerShell blocks `npm.ps1`. On macOS or Linux, use `npm` in place of `npm.cmd`.

`npm ci` installs the exact versions in [package-lock.json](package-lock.json). The first installation needs internet access to public npm dependencies and requires no npm account. The no-argument `prepare` installation lifecycle is a successful no-op; installation does not rebuild artwork. The prepared files are already included.

An extracted source ZIP needs **no Git installation, GitHub login, Google account, Drive connection, API key, or AI service**. Git is needed only when you choose to use Git commands. Once dependencies are installed, the checks and development site use local project files.

Run commands from the folder containing `package.json`.

| `npm.cmd run prepare -- --all` | Prepare all current drawings and photo derivatives. This does not review them. Full-collection work belongs to WP05. |
| `npm.cmd run prepare -- --all --include-archives` | Also regenerate retained historical region versions from their frozen recipes. |
| `npm.cmd run import -- --verify-existing` | Maintainer inventory/verification operation; ordinary setup does not need it. |
| `npm.cmd run prepare` | Print usage and succeed without reading sources or changing assets. |

These commands still report **exit code 4** for unfinished collection/release work:

```powershell
npm.cmd run validate
npm.cmd run catalog -- --mode release
npm.cmd run build
```

Full assets validation reports the unprepared collection; the selected check above is the WP02 check. Unqualified validation defaults to **release** validation. Release catalog and production build remain gated until later packages. Invalid source material can fail earlier with a different code. Full contracts are in [TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md).

Structured reports go under `.work/reports/`, except for no-argument prepare, which performs no file access. Exit codes: **2** invalid command/prerequisite; **3** invalid input/schema/hash; **4** incomplete or stale preparation; **5** processing/filesystem failure; **6** packaging/portability failure.

## Review or change the representative drawing

Run `npm.cmd run prepare -- --id design-002`. The report names `.work/review/design-002/<contentVersion>/`. Inspect `regions-numbered-2x.png`, `regions-colored.png`, `fill-sample.png`, and `correction-masks.png`. The JSON/CSV files give each region's bounds, seed, size, and centroid.

## Maintainer source import

The complete project already contains its materials. Reimport is for verification or a deliberate source update.

```powershell
npm.cmd run import -- --source-root "C:\path\to\Coloring Book"
```

That folder must contain the exact 55 JPEG filenames in the acquisition map and a `Coloring Pages` child with `002.png` through `049.png`. Optional history/cover groups can be supplied separately or together:

```powershell
npm.cmd run import -- --history-root "C:\path\to\histories" --cover-file "C:\path\to\Design_01_Front.png"
```

The history directory must contain `Church History 1928.docx`, `Church History 1935.docx`, `h28.txt`, and `h35.txt`. Import copies/verifies them; it does not extract DOCX text. Unselected local source groups remain available.

For an intentional replacement, leave the recorded source in place and supply the new file separately:

```powershell
npm.cmd run import -- --replace-source design-002 --replacement-file "C:\path\to\replacement.png"
npm.cmd run validate -- --stage catalog
```

The importer archives previous bytes and their receipt under `source/archive/`, updates acquisition/manifest records, and leaves descriptions alone. Refresh dependent preparation and reviews afterward. An interrupted promotion is recorded in `.work/promotion.json`; preserve it and rerun the original mutating command for recovery. Read the reported conflict if recovery cannot proceed.
